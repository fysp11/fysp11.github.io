## 2024-05-24 - React UI Image Loading Anti-Pattern
**Learning:** Astro's built-in `<Image />` component from `astro:assets` is not supported inside React UI components (`.tsx` files). Using it triggers errors or creates anti-patterns. Additionally, when rendering a list of images (e.g. `projects.map`), applying `loading="eager"` and `fetchPriority="high"` indiscriminately to all items causes severe network contention and defeats the purpose of resource prioritization.
**Action:** In React components within an Astro project, always use standard HTML `<img>` tags. When iterating over images, use the loop index (e.g., `index < 2`) to selectively apply `loading="eager"` and `fetchPriority="high"` only to above-the-fold content, leaving the rest to `loading="lazy"` and `fetchPriority="auto"`. Always append `decoding="async"` to prevent blocking the main thread.
