## 2024-02-18 - Astro Image Integration in React Components
**Learning:** Using Astro's built-in `<Image />` component from `astro:assets` inside React UI components (`.tsx` files) is not supported and will result in build/hydration errors. To retain build-time image optimizations (WebP conversion, resizing) for images inside a React client component, you must compute the optimized image URL at the server level (in the `.astro` file) using Astro's `getImage()` function. Also, passing a string path directly to `getImage()` requires providing both `width` and `height`, but it is much more efficient for local `/public` images to be resolved via `import.meta.glob<{ default: ImageMetadata }>('/public/.../*')` and passing the resolved module as the `src`.
**Action:** When working with images inside React components in an Astro project, pre-compute the optimized image URLs in the parent `.astro` file and pass them as string props to the `.tsx` component, replacing Astro `<Image>` components with standard HTML `<img>` tags. Implement optimal loading strategies on these standard tags (e.g., eager for initial viewport items, lazy for the rest).
