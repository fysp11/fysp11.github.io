## 2024-08-13 - Project Image Optimization & Hydration Fix
**Learning:** `astro:assets` `<Image>` component cannot be used inside React UI components (`.tsx`). It causes hydration issues and fails the build on unresolvable local assets when rendered client-side. The `<Image>` component is designed strictly for `.astro` files to take advantage of build-time processing.
**Action:** Always pre-optimize images at the server level in `.astro` files (using `getImage()` and `import.meta.glob` for local images), and pass the resolved optimized string URLs as props to React components. Inside `.tsx` files, only standard HTML `<img>` tags must be used. Additionally, never uniformly apply `loading="eager"` or `fetchPriority="high"` inside a mapped list of images, as this creates network contention. Apply it conditionally via loop indices (e.g., `index < 2`) for above-the-fold content, reserve `loading="lazy"` for the rest, and always include `decoding="async"` to not block the main thread.
