## 2024-05-24 - Pre-computing Astro optimized images for React UI components
**Learning:** Astro's built-in `<Image>` component from `astro:assets` is not supported inside React UI components (`.tsx` files). Using it inside React files leads to hydration errors, runtime warnings, or missing build-time optimizations (like WebP conversion or resizing). Furthermore, to optimize dynamically referenced images located in the `/public` directory inside Astro's `getImage()`, passing the string path directly is insufficient; you must first resolve the image to `ImageMetadata` using `import.meta.glob<{ default: ImageMetadata }>('/public/images/projects/*')`.
**Action:** When a React UI component requires optimized image rendering, compute the optimized image URL at the server level (in the `.astro` file) using Astro's `getImage()` function alongside `import.meta.glob`, then pass the string `.src` URL down to the React component as a prop to be rendered using a standard HTML `<img>` tag with appropriate loading attributes (e.g. `loading="eager"`, `fetchPriority="high"`, `decoding="async"` for above-the-fold images).
