## 2025-02-17 - React Component Image Loading Performance
**Learning:** Astro's `astro:assets` `<Image>` component fails in this project's `.tsx` React components. When rewriting to standard `<img>` tags, it is crucial to apply proper native performance attributes: `fetchPriority="high"` with `loading="eager"` for above-the-fold list items, and `loading="lazy"` for below-the-fold grid items, always with `decoding="async"` to prevent main-thread blocking. Additionally, it is required to add inline comments to explain these optimizations to satisfy user constraints.
**Action:** When working on images inside React components, use `<img>`, set `decoding="async"`, manage `fetchPriority` appropriately, and always document the performance fix directly in the code with comments.
