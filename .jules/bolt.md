## 2025-02-20 - Image Rendering Bottlenecks in Mixed Framework Contexts
**Learning:** Using Astro's `<Image />` component inside React UI components (`.tsx`) is an anti-pattern as it is not fully supported and can lead to runtime issues or bypass build-time optimizations (like WebP conversion and resizing). Additionally, applying `loading="eager"` and `fetchpriority="high"` globally to all images in a list causes significant network contention and blocks rendering.
**Action:** Always compute optimized image URLs server-side (in `.astro` files) using Astro's `getImage()` coupled with `import.meta.glob`, and pass the resulting string URLs to React components as props. Use standard HTML `<img>` tags in React, and conditionally apply eager loading and high fetch priority based on loop indices (e.g., `index < 2`) to prioritize only above-the-fold content while utilizing lazy loading for the rest.
