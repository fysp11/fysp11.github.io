## 2024-03-24 - [Avoid Astro Image in React Components]
**Learning:** In Astro projects, using the `<Image />` component from `astro:assets` inside React components (`.tsx`) is not fully supported and can cause issues. Instead, server-side code (in `.astro` files) should resolve the image modules (e.g. using `import.meta.glob`) and optionally optimize them with `getImage()`, then pass the string URL down to the React component which renders a standard HTML `<img>` tag.
**Action:** When rendering images in React components within an Astro project, use standard `<img>` tags and compute the optimized image URL server-side. Additionally, do not apply `loading="lazy"` and `fetchpriority="low"` blindly in loops without applying eager loading to above-the-fold images to avoid network contention.
