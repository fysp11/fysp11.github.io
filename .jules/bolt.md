## 2025-02-06 - Replacing <Image> in React Components
**Learning:** Using Astro's `<Image />` component inside React (`.tsx`) files throws an error or fails to compile in this specific project architecture since they are evaluated at build time within Astro's server scope. Using a fallback standard `<img />` loses critical build-time resizing and format conversion optimizations (e.g., converting to webp).
**Action:** When dynamically rendering images within React components that require build-time optimization, compute the optimized URLs at the Astro page level using `import.meta.glob<{ default: ImageMetadata }>` to resolve the image and then calling Astro's `getImage()` function. Pass the resulting `.src` paths as props to the React component to use with standard `<img>` tags along with standard performance attributes (e.g. `loading="eager"` and `fetchPriority="high"` for main images).
