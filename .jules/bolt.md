## 2025-02-28 - Optimizing Astro Image Components inside React UI
**Learning:** Astro's built-in `<Image />` component from `astro:assets` is not natively supported inside React UI components (`.tsx` files), and fails to process dynamically referenced images correctly when the source is simply a path string (e.g. `src={project.image}`). This prevents critical build-time performance benefits like WebP conversion, automatic resizing, and layout optimizations.
**Action:** Always compute the optimized image URL at the server level (in the `.astro` file) using Astro's `getImage()` function (importantly using `import.meta.glob` to retrieve the `ImageMetadata` instance instead of passing the plain string directly). Pass these optimized string URLs as props down to the React component, and use a standard HTML `<img>` tag with proper attributes (`loading="eager"`, `fetchPriority="high"`, `decoding="async"`) inside the `.tsx` file to maintain peak performance and fast LCP.
