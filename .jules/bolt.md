## 2023-10-27 - Image Render Contention & Astro Astro:Assets Integration in React
**Learning:** Using Astro's built-in `<Image />` component inside `.tsx` files is an anti-pattern that leads to invalid imports and frontend bugs because Astro's internal logic cannot process React UI correctly at build time. Additionally, rendering image lists where all elements blindly get `loading="eager"` or `fetchpriority="high"` causes intense network contention at initialization, delaying critical asset downloads.
**Action:** Always extract the optimized WebP string paths at the server level inside `.astro` files using Astro's `getImage()` combined with `import.meta.glob`, then pass the raw strings down to standard HTML `<img>` tags in `.tsx` views. When mapping over image arrays, utilize the loop `index` conditionally to apply `loading="eager"` and `fetchPriority="high"` *only* to the first few elements above the fold, fallback to lazy loading, and always append `decoding="async"`.
